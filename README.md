# 🖥️ Nexus OS 26

> 小方工作室出品 ｜ 跑在浏览器里的桌面系统 ｜ MIT

**一个 HTML 文件，双击就是一个完整的操作系统。**

没有安装包，没有 Node，没有 `npm install`。`nexus os 26/Nexus OS 26.html` 双击打开，锁屏、开机动画、桌面、Dock、25 个应用全都在。

---

## 🚀 现在就能跑

**方式一 · 直接双击**

打开 `nexus os 26/Nexus OS 26.html`。

**方式二 · 本地起个服务**（少数功能如剪贴板、部分 API 在 `file://` 下会被浏览器限制）

```bash
cd "nexus os 26"
python -m http.server 8080
# 然后访问 http://localhost:8080/Nexus%20OS%2026.html
```

进了系统先玩这几处：

| 做什么 | 怎么做 |
| --- | --- |
| 换皮肤 | 设置 → 外观 → Flat / Neu / Liquid 三套任切 |
| 换主题色 | 设置 → 主题色，最多存 3 个主色，副色无限 |
| 换壁纸 | 桌面右键，或 设置 → 壁纸（锁屏壁纸独立） |
| 问 AI | Dock 上的「小方」，全屏输入、思考模式、音色语速都在设置里 |
| 看真系统什么样 | 开始菜单 → 任务管理器 / 终端 / 虚拟机 / 应用商店 |

## 🎨 视觉体系

三套皮肤共用一套令牌，切换只换材质不换结构：

| 皮肤 | 材质 | `data-ui` |
| --- | --- | --- |
| **Flat** | 纯扁平，零阴影零模糊，低配机器最省 | `flat` |
| **Neu** | 新拟物，双向阴影，凸起与凹陷 | `neu` |
| **Liquid** | 液态玻璃，真折射不是假渐变 | `liquid` |

几条硬规矩，全系统通用：

- **永远不用 `#FFFFFF` 和 `#000000`**，层次只靠 3% / 5% 明度微差拉开——纯白纯黑会把玻璃质感直接压死。
- **磨砂玻璃四档强度**（弱 → 强），面板用磨砂，Dock 三段用液态玻璃，两者不混用。
- **对比度铁律**：白底必须黑字，黑底必须白字，任何"白底白字"都算 bug。
- **液态玻璃是真折射**：`fangui/liquid/liquid-glass-core.js` 用 SVG 滤镜 + `feImage` 做位移贴图，`refract.js` 负责边缘色散。不是叠一层 `backdrop-filter: blur()` 糊弄。

FangUI 本体在 `nexus os 26/fangui/`，跟 [fangUI](https://github.com/xiaofangstudio/fangui) 同源。

## 🤖 AI 小方

系统内置的助手，走自己的对话层，支持：

- 历史会话、新建对话、思考模式开关
- 音色与语速、一键静音
- 输入框上下拉伸、全屏输入
- Agent 分层说明面板

模型侧默认 `deepseek-flash`，接口地址和 Key 在 设置 → AI 里填，不写死在代码里。

## 👤 账号系统

前端面板、注册三步向导、三种登录方式（账户名 / 7 位账户号 / UID）、邮箱验证码、好友页签都在系统里，实测可用。

**后端不在本仓库**：账号服务是一套 Cloudflare Worker + D1 + KV + Turnstile，独立部署。仓库里只有前端调用层，没有 Worker 源码，也没有任何密钥。想接自己的后端，改 设置 → 账号 里的接口地址即可。

## 🛠 改它

纯静态，没有构建步骤，改完刷新就生效。

```bash
git clone https://github.com/xiaofangstudio/Nexus-OS-26.git
cd "Nexus-OS-26/nexus os 26"
# 直接编辑 Nexus OS 26.html / apps/*.html / ui/*.css / fangui/**
python -m http.server 8080
```

- 加一个应用：复制 `apps/_template.html`，放进 `apps/`，在系统外壳里注册图标与窗口尺寸。
- 改材质：`fangui/core/` 下 `tokens.css` 是令牌，`flat.css` / `neu.css` / `liquid.css` 是三种材质实现。
- 改图标：往 `Small icon/` 丢 SVG，命名规则跟现有保持一致。

## ⚠️ 已知边界

- **小游戏启动器**指向 `../../小游戏/工具与小游戏.html`，那是整个「小方规划」工作区里的另一个目录，单独 clone 本仓库时这个入口会打不开——其余 24 个应用不受影响。
- 账号系统只有前端，后端要自己部署。
- 少数能力（剪贴板、部分设备 API）在 `file://` 下会被浏览器拦，用本地服务起更完整。
- 仓库里的 `.trash/` 目录（历史备份与调试截图）没有上传，它只是开发期的备份堆。
