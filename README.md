## 🚀 怎么用

1. 打开 `nexus os 26/Nexus OS 26.html`
2. 进桌面，点 Dock 或启动台开应用
3. 要配 AI：设置 → 系统 → AI 模块，添加你的 API

电脑版更详细的说明见 [`nexus os 26/README.md`](nexus os 26/README.md)。
