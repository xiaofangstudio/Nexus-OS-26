精准触控板审计

结论：触控板目前只活在首次引导里。引导之外，系统没有手势总线，也没有任何一处做滚轮归一化、惯性和多指识别。以下为逐项审计，代码位置以主壳函数名为准（主壳正被并发修改，行号不稳定）。

缺失

#缺失项影响备注
1系统级手势总线全局没有任何 N26Gestures 单例
2滚轮归一化 + 惯性 + 回弹所有列表 / 文档 / 设置完全依赖系统原生滚动
3鼠标滚轮 vs 触控板区分全局全库只有 ctrlKey 判断
4三指手势启动台 / 桌面 / 切应用完全缺失，Web 拿不到手指数
5边缘滑动浏览器 / 文件管理完全缺失
6轻点拖拽 / 三指拖移窗口 / 图层 / 文件只有 DockNav 长按拖动，不通用
7手势调试 HUD调试无
8识别失败回退策略全局无
9教程「拖动」步骤新手引导文案反复说「不要拖动」
10设置里的触控板面板设置全库无「触控板」设置项
11相册双指 / 滚轮缩放相册只有按钮
12浏览器手势后退 / 页面缩放浏览器iframe 内无手势
13文件拖移 / 边缘返回文件管理只有按钮
14方哩方哩横向条的双指横滚方哩方哩apps/bili 已有 overflow-x 横向条（.cw-row），但纵向滚轮不会转横向
15地图应用—全库无地图实现
16iframe 应用手势接入所有拆分应用主壳收不到子文档的 wheel

冲突

#冲突位置后果处理
1canvas wheel 无条件缩放星空 / 天气地球滚动与缩放同时发生全局层遇 canvas 直接放行
2图片查看器任意滚轮都缩放apps/image.html无法纵向滚动，与惯性叠加抖动改为 ctrl / 捏合才缩放
3锁屏滚轮上推解锁#lock-screen解锁滚轮被吃锁屏可见时整层暂停
4启动台滚轮翻页#launchpad横滑被判成三指，翻页失效标记 data-n26-gestures="off"
5教程同时监听 wheel 与 gesturen26-tour.jsSafari 捏合算两次，缩放跳变gesture 存在时忽略 ctrl+wheel
6窗口拖动 mousedownstartDrag全局 tap-drag 抢事件会拖不动窗口全局拖移只走显式 enableDrag
7ctrl+wheel = 浏览器整页缩放壳层整个 OS UI 被放大默认 blockPageZoom
8教程舞台 wheel preventDefaultn26-tour.js弹窗背后无法滚动（预期）引导层加 gestures="off"
9多层横向容器设置 / 商店 / tabs横滚被最外层吃掉从光标向上找最近可横滚祖先
10主壳正被并发写入Nexus OS 26.html行号漂移，改错风险本轮不动主壳；接入前备份 + 静置确认
三个硬约束：浏览器拿不到手指数，三指只能靠滚轮爆发形态推断，默认关闭； iframe 是独立文档，手势层必须由应用自己引入或同源注入； Web 没有旋转手势，相册「旋转」只能保留按钮 / 快捷键。

全局手势映射

优先级：应用 claim > 系统默认 > 原生行为。任何一步识别失败都放行，不吞事件。

手势识别条件系统默认应用覆盖点失败时
双指上下滑非 ctrl，deltaY 主导最近可纵向滚动祖先：归一化 + 惯性 + 边缘阻力设置 / 商店调摩擦；画布 claim 自处理放行原生
双指横滑非 ctrl，deltaX 主导最近可横滚祖先横滚方哩方哩 rail / tabs / 时间线放行原生
双指捏合ctrl + wheel 或 gesturechange命中图片则按光标锚点缩放相册 / 地图 / Strata / Reelix / 浏览器吞掉整页缩放（可配）
三指上滑≤300ms，|Δy|≥384，非滚动区打开启动台应用可 intercept不动
三指下滑同上反向显示桌面（最小化全部）应用可 intercept不动
三指左 / 右滑≤420ms，|Δx|≥240，|Δx|>1.5|Δy|上一个 / 下一个应用data-n26-gesture-3="history" 时改前进后退不动
左缘右滑起点 x≤26，Δx>30，|Δy|<30当前窗口返回浏览器 / 文件管理 / 阅读器轻微回弹
右缘左滑起点 x≥屏宽-26，Δx<-30当前窗口前进同上轻微回弹
轻点拖拽enableDrag 宿主 + 位移>4px窗口 / 图层 / 文件拖移，data-n26-drop 吸附相册排序、桌面图标、图层当作点击
长按拖动按住 280ms 后移动保留 DockNav 排序—无动作

接入主壳步骤（下一轮）

#动作说明
1备份主壳Nexus OS 26.html → .bak-日期-gestures
2确认稳定连续 5 分钟无写入（当前正被并发修改）
3引入脚本<script src="ui/n26-gestures.js?v=...></script> 放 body 末
4注册默认动作swipe3 → 启动台 / 桌面 / 切应用；edge → 浏览器与文件历史
5标记禁区锁屏、启动台、引导层加 data-n26-gestures="off"
6iframe 桥扩展 apps/_bridge.js 回报 gesture，避免每个应用重复监听
调试入口：控制台 N26Gestures.debug(true) 显示 HUD； N26Gestures.state() 看当前配置与识别状态； N26Gestures.configure({threeFinger:true}) 打开三指推断。
