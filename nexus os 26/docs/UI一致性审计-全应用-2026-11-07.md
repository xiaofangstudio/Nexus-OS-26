# Nexus OS 26 · 全应用 UI 一致性审计

- 审计日期：2026-11-07
- 审计范围：`apps/` 下 36 个应用入口（35 个纳入整改评估 + 1 个嵌套系统豁免）（含 `bili/`、`float/`、`floatapp/`、`htmlapp/`、`necta/`、`reelix/`、`strata/`；排除 `_template`、`_ui-demo` 与 `float/.build` 构建产物）
- 审计基准：`docs/UI硬标准.md`（以下简称“硬标准”）、`docs/精准触控板-审计与手势映射.md`
- 审计方式：只读静态审计。逐文件读取 CSS 规则、DOM 结构、共享层加载顺序与 token 使用；未修改任何应用文件。
- 重要说明：该目录存在并发改动，本文行号是 2026-11-07 的静态快照。打补丁前请用选择器重新定位，不要按行号整段覆盖。

## 严重度定义

| 级别 | 含义 | 处理建议 |
|---|---|---|
| P0 | 硬标准直接失效：玻璃不跟随、深浅色不跟随、侧栏完全不是玻璃 | 公共层先修，影响面最大 |
| P1 | 明显不一致：侧栏几何、应用图标非超椭圆、正文对比度 <4.5、主交互无语义、触控板冲突 | 本轮修 |
| P2 | 细节漂移：字号/圆角/阴影/z-index/过渡使用临时值 | 顺手修，不单独排期 |
| P3 | 风险或备注：独立打开失效、性能模式未降级、跨域限制 | 记录，不阻塞 |

## 0. 结论摘要

1. **最严重的问题不在单个应用，而在共享层**：`.n26-glass` 这个“官方玻璃类”写死了 `18px` 模糊与固定透明度，**不消费 `--n26-blur / --n26-glass-alpha / --n26-glass-sat`**。用它的 9 个应用（agent、image、map、fangchat、fangwork、music、quicknote、terminal、screenshot）在拖动玻璃滑杆时都不会变化。
2. **N26UI 的侧栏根本不是磨砂玻璃**：`ui/n26-ui.css` 的 `.n26ui-sidebar` 只有半透明白底，没有 `backdrop-filter`，也写死 `rgba(255,255,255,.50)`。使用 `N26UI.createShell` 的 5 个应用（camera、excel、map、ppt、word）全部受影响；music 自己打了补丁，是唯一例外。
3. **6 个应用没有主题桥**：`devstudio`、`htmlapp`、`float`、`strata`、`reelix` 不加载 `_app.js`，`vm-os1` 为嵌套系统豁免。另有 `necta`、`floatapp`、`vm` 虽然加载了 `_app.js`，但 CSS 完全不认 `body.dark-mode`，实际是固定深色。
4. **9 个应用已经做到 0 硬编码色值**：image、terminal、video、screenshot、quicknote、camera、excel、ppt、word。它们应作为后续改造的参照，而不是被“统一”回退。
5. **应用图标是明显的漏网项**：games、monitor、fangwork、fangchat、necta、htmlapp 的 app/brand 图标都是普通 `border-radius`，只有 agent 和 screenshot 用了超椭圆。
6. **没有发现“点了完全没反应”的假按钮**；但 devstudio、games、tips 的主交互使用了 `div onclick`，没有 `role` / `tabindex` / 键盘路径，属于可达性不合格。

## 1. 公共层根因（先修这里，一次覆盖多个应用）

### 1.1 P0：`.n26-glass` 不跟随玻璃滑杆

证据：`apps/_polish.css:L208-L231`

```css
.n26-glass {
  background: rgba(18, 22, 30, 0.62);
  backdrop-filter: blur(18px) saturate(1.25);
}
html[data-mode="light"] .n26-glass {
  background: rgba(250, 252, 255, 0.68);
}
```

- 模糊固定 `18px`，没有 `var(--n26-blur)`。
- 透明度固定 `.62/.68`，没有 `var(--n26-glass-alpha)`。
- 饱和度固定 `1.25`，没有 `var(--n26-glass-sat)`。

受影响应用（使用 `.n26-glass` 的位置）：agent、image、map、fangchat、fangwork、music、quicknote、terminal、screenshot。

建议改法（只改公共层，不动视觉语言）：

```css
.n26-glass {
  background: color-mix(in srgb,
    var(--surface-glass, #fafcff) calc(var(--n26-glass-alpha, .55) * 100%),
    transparent);
  backdrop-filter: blur(var(--n26-blur, 18px)) saturate(var(--n26-glass-sat, 125%));
  -webkit-backdrop-filter: blur(var(--n26-blur, 18px)) saturate(var(--n26-glass-sat, 125%));
}
```

保留 L262/L273 已有的 `body.perf-mode` 与 `mat-solid` 降级分支，不要删。

### 1.2 P0：N26UI 侧栏不是磨砂玻璃

证据：`ui/n26-ui.css:L30-L44`（`.n26ui-sidebar`）

- 只有 `background: rgba(255,255,255,.50)` 与深色 `.07`。
- 没有 `backdrop-filter`，也没有 `--n26-*` 变量。
- `apps/_polish.css:L309-L347` 的侧栏白名单不含 `.n26ui-sidebar`，因此 `_app.js` 注入的 `_polish.css` 也兜不住。

受影响：`camera.html`、`excel.html`、`map.html`、`ppt.html`、`word.html`。music 自己在 `apps/music.html:L82-L87` 用 `--n26-blur` 补了模糊，是唯一正确的用法。

建议：在 `ui/n26-ui.css` 里补：

```css
.n26ui-sidebar {
  background: rgba(255, 255, 255, var(--n26-glass-alpha, .50));
  -webkit-backdrop-filter: blur(var(--n26-blur, 17px)) saturate(var(--n26-glass-sat, 180%));
  backdrop-filter: blur(var(--n26-blur, 17px)) saturate(var(--n26-glass-sat, 180%));
}
body.dark-mode .n26ui-sidebar,
html[data-mode="dark"] .n26ui-sidebar {
  background: rgba(20, 24, 33, var(--n26-glass-alpha, .50));
}
```

同时把 L184 的 `html[data-theme="dark"]` 补成 `:is(html[data-theme="dark"], html[data-mode="dark"])`——平台实际写的是 `data-mode`，不是 `data-theme`。

### 1.3 P0：主题桥缺失

`_app.js` 是唯一把宿主 `data-mode`、`body.mat-solid`、`body.perf-mode`、`--n26-*` 注入 iframe 的层。以下入口没有加载它：

| 应用 | 现状 | 结果 |
|---|---|---|
| `apps/devstudio.html` | 只加载 `tokens.css`、`devstudio.css`、`n26-docknav.css` | 永远浅色；自带 `body.dark-mode` 规则永远不触发 |
| `apps/htmlapp/index.html` | 只加载 `devstudio-preview.js` | 永远浅色；`body.dark-mode` 规则是死代码 |
| `apps/float/index.html` | 只引 `_polish.css` + 自带 bundle | 主题/玻璃滑杆均不跟随 |
| `apps/strata/index.html` | 自带 `prefers-color-scheme` + `data-theme` | 跟随系统，不跟随 Nexus 宿主 |
| `apps/reelix/index.html` | `html data-theme="light"` + 自带暗色主题 | 跟随自身开关，不跟随 Nexus 宿主 |
| `apps/vm-os1/Nexus OS.html` | 嵌套系统模拟器 | **豁免**，不建议纳入统一改造 |

另有 3 个“加载了但不用”的应用：`necta`、`floatapp`、`vm`。它们的 CSS 没有任何 `dark-mode` 选择器，固定深色。

建议：
- 所有应用入口强制加载 `apps/_app.js`；在 `_template.html` 之外加一条构建/提交检查（缺 `_app.js` 直接失败）。
- `strata` / `reelix` / `float` 三个 bundle 应用最小改造：只加载 `apps/_bridge.js`（或等价 30 行适配器），监听主题消息后写 `document.documentElement.dataset.theme = dark ? 'dark' : 'light'`，并读取 `--n26-blur` 覆盖自身玻璃变量。不要改它们的整套设计系统。

### 1.4 P1：应用图标不是超椭圆

硬标准 M-16/M-74 要求 22.4% 圆角方形或超椭圆；全仓只有 `agent`（`L50/L55`）与 `screenshot`（`L85`）用了 `corner-shape: squircle`。

| 应用 | 证据 | 现状 |
|---|---|---|
| `games.html` | L37-L39 `.app-icon` | `border-radius:10px`，34px 图标 |
| `monitor.html` | L44-L49 `.app-icon` | `border-radius:10px`，且渐变里直接写 `#3b82f6` |
| `fangwork.html` | L133 `.logo`、L173 `.c-icon` | `9px` / `12px` 普通圆角 |
| `fangchat.html` | L323 `.fc-about-brand .logo` | `16px` 普通圆角 |
| `necta/index.html` | L68 `.nt-brand img` | `9px` 普通圆角 |
| `htmlapp/index.html` | L75 `.ha-logo`、L125 `.mark` | `8px` / `16px` 普通圆角 |

建议：抽一个 `.n26-app-icon` 公共类，统一 `border-radius:22.4%; corner-shape:squircle;`，并给不支持 `corner-shape` 的浏览器补 SVG `clip-path`。逐应用只替换 class，不要重画图标。

### 1.5 P1：正文对比度不足

按 WCAG 计算（浅色最差背景）：

| 应用 | 证据 | 实测 | 承载内容 |
|---|---|---|---|
| `agent.html` | `--ink3 #9aa0b5`（L11）用于 L96 系统气泡 | **2.39:1** | 系统消息、思考文本（正文） |
| `fangchat.html` | `--fc-text-sub`（alpha .55）用于 L143 会话预览 | **4.00:1** | 11.5px 消息预览（正文） |
| `duolingo.html` | `--ink-2`（alpha .56）用于 L103 副标题 | **3.83:1** | 12.5px 课程说明（正文） |
| `monitor.html` | `--sub`（alpha .55）用于 L51/L76/L309 表格与卡片 | **3.45:1** | 数据行/状态文本（正文） |

建议：只把这些“承载正文”的用法提到 `.62` 档，或直接换安全色；不要改全局 `--text-3`。
- agent：`#667085` on `#eef6ff` ≈ 4.56:1。
- fangchat / duolingo / monitor：`rgba(15,23,42,.62)` ≈ 5.0:1。

## 4. 统一建议：应该抽成公共层的部分

1. **玻璃材质层（最高优先）**
   - 修 `.n26-glass` / `.n26-glass-strong`，让它们消费 `--n26-blur / --n26-glass-alpha / --n26-glass-sat`。
   - 修 `.n26ui-sidebar`，让 N26UI 的侧栏天然是磨砂玻璃。
   - 保留 `body.perf-mode` 与 `body.mat-solid` 降级分支；所有自定义 blur 也必须响应这两个类。
2. **主题桥（次高）**
   - 把 `_app.js` 设为所有应用入口的硬依赖；缺它直接视为不合格。
   - 给 bundle 应用（strata、reelix、float）提供 30 行 `n26-theme-adapter.js`，只做三件事：接收主题、写 `data-theme`、暴露 `--n26-*`。
3. **应用图标组件**
   - `.n26-app-icon`：`border-radius:22.4%; corner-shape:squircle;`，附 SVG `clip-path` 兜底。
   - 先替换 6 个漏网图标，不动其他视觉。
4. **侧栏几何 token**
   - 建议新增：`--dock-w:76px`、`--dock-radius:16px`、`--dock-item-radius:11px`、`--dock-label:10.5px`、`--dock-icon:15px`。
   - 让 bili（66px）、fangchat（62px）、quicknote（72px）与 devstudio（13px/6px）向 token 靠拢，而不是各写一套。
5. **文字对比度**
   - 只修“承载正文”的 `.55` 档，不全局改 `--text-2`。
   - 建议在标准里补一条：`--text-2` 只能用于标签/辅助，正文必须使用 `--text-1` 或对比度 ≥4.5 的派生色。
6. **动效 token**
   - 统一 `--dur-fast/base/slow` 与 `--ease-out-expo` 等；替换 7 处 `transition: all`。
   - 明确例外：不确定进度环/加载 spinner 可以用 linear，但必须加 `perf-mode` 降级。
7. **z-index 层级**
   - 全部换 `--z-panel(900) / --z-overlay(1000) / --z-modal(1100) / --z-toast(1200) / --z-boot(2000)`；清理 9000/9999/1200/1100 等字面量。
8. **触控板接入规范**
   - 提供 `N26Trackpad.claim(el, { wheel: 'native' | 'zoom', pan: 'native' | 'none' })`。
   - map 的惯性、terminal 的回看、music/video 的滚轮音量应显式 claim；canvas 由公共层自动跳过。
9. **不要做的事**
   - 不要为了“统一”把单视图应用（focus、pomodoro、calculator、colorlab、game2048）套上侧栏。
   - 不要重画图片/视频/相机等专业工作区；只替换 token、玻璃与图标形状。
   - 不要整文件覆盖正在并发修改的应用；按选择器做最小 diff。
