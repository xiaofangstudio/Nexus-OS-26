# 计算器 · 键盘映射

适用版本：`apps/calculator.html`（Nexus OS 26 深度改造版）
测试环境：Edge / Chromium，窗口 320×480 与 280×380 均无溢出。

## 一、标准 / 科学模式

| 按键 | 功能 | 等价按键 |
| --- | --- | --- |
| `0`–`9` | 输入数字 | 数字键 |
| `.` / `,` | 小数点 | `.` |
| `+` | 加 | `+` |
| `-` | 减 | `−` |
| `*` 或 `x` / `X` | 乘 | `×` |
| `/` | 除 | `÷` |
| `%` | 百分号（÷100） | `%` |
| `^` | 乘方 | `xʸ` |
| `(` `)` | 括号 | `(` `)` |
| `Enter` 或 `=` | 求值 | `=` |
| `Backspace` | 退一格 | ⌫ |
| `Delete` | 全部清除 | `AC` |
| `Esc` | 清空；历史浮层打开时先关闭浮层 | `AC` |
| `↑` | 上一条历史回填 | 历史条目 |
| `↓` | 下一条历史回填 | 历史条目 |
| `Ctrl/⌘ + H` | 打开 / 关闭历史记录 | 右上角时钟图标 |
| `Ctrl/⌘ + C` | 复制当前结果 | 点击结果数字 |

## 二、科学模式追加

| 按键 | 功能 |
| --- | --- |
| `S` | sin |
| `C` | cos |
| `T` | tan |
| `L` | ln（自然对数） |
| `G` | log（常用对数） |
| `R` | √（平方根） |
| `Q` | x²（平方） |
| `P` | π |
| `E` | ℯ（自然常数） |
| `D` | 切换 DEG / RAD |

> 三角函数按当前 DEG / RAD 计算；`tan 90°`、`ln 0`、`√-9` 等无定义输入会给出中文提示并以抖动反馈，不会输出错误数值。

## 三、换算模式

| 按键 | 功能 |
| --- | --- |
| `0`–`9`、`.` | 直接写入换算输入框（焦点不在输入框时） |
| `Backspace` | 退一格 |
| `Esc` | 退出输入框焦点 |
| 点击输入框后 | 走系统原生文本输入，支持负号、小数 |
| `←` / `→`（焦点在分类胶囊上） | 切换换算类别 |
| `Enter` / `Space`（焦点在结果上） | 复制换算结果 |

## 四、通用

| 按键 | 功能 |
| --- | --- |
| `Tab` | 焦点在顶部分段控件上时逐项切换，`←` / `→` / `Home` / `End` 快速换模式 |
| `Space` / `Enter`（焦点在结果数字上） | 复制结果 |

## 五、运算规则说明

- 优先级：`()` → 函数 → 乘方（右结合）→ 一元正负 → `× ÷`（含隐式乘法，如 `2π`、`2(3+4)`）→ `+ −`。
- 浮点显示按 12 位有效数字收敛，`0.1 + 0.2` 输出 `0.3`，不会出现 `0.30000000000000004`。
- 除以 0、负数开平方、对数非正数、结果超出实数范围，均以红色提示 + 抖动反馈，需 `Esc` / `AC` 清除。
- 求值后继续按运算符，会以当前结果为左操作数，符合连续运算习惯（`12+8=` → `20`，再按 `×2=` → `40`）。
