## 🆕 本轮更新了什么

这一版是奔着「发布级、别人没有的差异化」去的。Dock Bar 整个 2.0 落地，还补了一堆以前「点了白屏」的坑。

| 新东西 | 说白了就是 |
| --- | --- |
| 🎛️ **Dock Bar 2.0（对标 Touch Bar）** | Dock 上方多一条会「按场景长出来」的细条：能放标题 + 磁贴 + 按钮 + 文字；贴四条边都行、四套皮肤自动适配；**全屏自动收起**把地方让给应用；应用点一下直接收到回传 |
| 🤖 **AI 模块 + AI Switch** | 设置里能加多个 AI API（多 key 轮询）、切当前模型、一键测连通；第三方应用调 `aiChat` 时**密钥不出宿主**，由系统代理请求，别人拿不到你的 Key |
| 🧩 **补齐 4 个「点了白屏」的应用** | 虚拟机（自包含：开机动画→桌面，内置便签 / 计算器 / 画图 / 文件盒，能拖入本地 `.html` 运行，**全内存、关闭即焚、与宿主隔离**）、桌面沙盒（隔离 iframe 里跑 URL / HTML）、开发者工坊（写代码 + 实时预览 + 发布到本机）、小游戏合集（收录 **45 款**，搜索 / 分类 / 随机） |
| 🔒 **锁屏 2.0** | 高斯模糊 + 上滑解锁、真实电量、通知中心 |
| 📸 **截图录屏** | 真实捕获 → 存进系统盘 → File System Access 导出；录屏时 Dock Bar 直接显示**红色计时 + 「截一张 / 停止」** |
| 📈 **资源监视器** | 用真实 API 读 FPS / 内存，不是编的数字 |
| 🔌 **系统桥 API 升级** | `sendSystemMessage`（发系统通知）、`osControl`（开应用 / 改设置 / 电源）、`dockbar`（第一方第三方同一套），并支持异步能力（`aiChat`） |
| 🎮 **小游戏与应用界面打磨** | **2048 大升级**，游戏合集、小说、闹钟、开发者工坊、资源监视、截图、虚拟机等一批应用的界面与体验优化 |

一句话：**从「能跑的伪系统」往「发布级真系统」迈了一大步。**

## ✨ 它有什么

| 场景 | 说明 |
| --- | --- |
| 🖥️ **桌面与窗口** | 多窗口自由拖拽 / 叠放 / 最小化，Dock 四边摆放，启动台、右键菜单、通知中心 |
| 🧩 **应用生态** | 自带一批第一方应用；第三方应用走统一的宿主桥（文件、AI、通知、系统操控都有 API） |
| 🎛️ **Dock Bar** | 场景化的操控细条，第一方与第三方共用同一套接口 |
| 🤖 **AI 模块** | 多 API 管理 + 模型切换，密钥由宿主保管、不落第三方 |
| 🎨 **FangUI 四套皮肤** | `flat` / `neu-solid` / `neu-glass` / `liquid`，玻璃质感随风格变化，Dock Bar 一起适配 |
| 💾 **本地优先** | 所有数据存本地（`Nexus.getUserLS/setUserLS`），不联网 |

## 🎨 设计铁律

- 动画一律**非线性**（走 `--ease-*` 曲线），不做生硬直线
- 玻璃**克制 + 强磨砂**，不糊一脸
- **不露馅**：空态 / 错误态 / 深浅色双套 / 滚动边界都要有
- 第一方和第三方应用，**风格四套统一**

## 🚀 怎么用

1. 用浏览器打开 `Nexus OS 26.html`
2. 进桌面，点 Dock 或启动台开应用
3. 要配 AI：设置 → 系统 → AI 模块，添加你的 API 即可
